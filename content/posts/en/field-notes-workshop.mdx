This place is a workshop more than a magazine. The point of writing here is to take something apart in public - a circuit, a chord, a room's acoustics - and the page has to keep up with that. So before anything else, a tour of the tools, using each one in the spot where it earns its keep.

Every post starts as a plain text file with a little header on top:

```yaml
title: "…"
description: "…"
date: 2026-06-03
tags: ["audio", "music"]
dropCap: true
```

<Callout kind="info">
That header is validated when the site is built. If a date is malformed or the description runs too long, the build stops - better a failed build than a broken page.
</Callout>

## The body

The body is set justified with automatic hyphenation, on a measure of roughly sixty-eight characters so the eye never has to travel too far. When a single line deserves to stand on its own, it gets pulled out:

<Quote cite="A note to myself">
Build the tool first, then let the writing lean on it.
</Quote>

## When the page needs math

Audio work is full of small, honest equations. Inline, a level ratio is just $L = 20\log_{10}(p/p_0)$; set on its own line it has room to breathe:

$$
\text{SPL} = 20\log_{10}\!\left(\frac{p}{p_0}\right)\,\si{dB}, \qquad p_0 = 20\,\mu\mathrm{Pa}
$$

The notation is rendered once, at build time - no heavy script ships to the reader.
